**MORVANE — Hold the Last Lantern.** A top-down arena shooter that plays offline in a desktop browser. The Gloom has swallowed the drowned city, and one lantern still burns — yours. Survive fifteen waves of shades, spend the shards they drop on lantern upgrades between waves, and defeat the Umbral Maw to bring back the dawn. Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` directly in a desktop browser. No build step, no network requests, no assets to download.

## How to play

- **Move** — WASD / arrow keys
- **Aim** — mouse
- **Fire** — hold click / Space
- **Dash** — Shift / right click (brief invulnerability)
- **Pause** — P · **Mute** — M

Between waves, the shop offers three lantern upgrades — spend shards on more bolts, faster fire, piercing shots, orbiting wisps, a nova pulse, and more. Bosses wait at waves 5, 10 and 15. Your best score is kept in the browser.
